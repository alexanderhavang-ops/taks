Render a very compact operator-facing HTML card for the timeline domain as a mini-TNR.

Use:
- headline
- window
- lanes

Goals:
- a short title capturing headline.important
- optionally one very short supporting line
- a mini-TNR with 8h back and 8h forward
- Swedish local time
- almost no text inside the chart

Graphics:
- prefer a single horizontal time axis
- no swimlanes if they make the card worse
- use symbols for point items
- use bands for ongoing intervals
- let <title> carry details
- keep visible labels to an absolute minimum

Prioritize:
- enemy near now
- chatter / order effect that still matters
- mission ongoing now
- weather affecting now or the next few hours

Do not:
- no full summary inside the chart
- no legend
- no decorative flourishes
- no dense text
- no long time strings
- no labels that collide

If several objects are close:
- keep only the most important ones
- stack symbols lightly in height if needed
- shorten labels hard
- or show only symbol + <title>

The card should feel like:
- quick scanning
- situational pulse
- not a briefing graphic

Show only what clearly helps the user right now.
